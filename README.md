# Mini Factory Tycoon — Prototype 0.1

Первый браузерный прототип игры на Phaser 3.

## Что уже работает

- Вид сверху (top-down), перемещение WASD / стрелками.
- Сенсорные кнопки для телефонов и планшетов.
- Склад сырья: взять до 3 заготовок.
- Станок: запустить производство, дождаться готовности и забрать коробку.
- Зона отгрузки: продать коробки за внутриигровые деньги.
- Мастерская: улучшить скорость станка за ₽100 × уровень.
- Локальное сохранение через localStorage.
- Подключение Yandex Games SDK с безопасным fallback для локального запуска.
- Кнопка rewarded video с начислением бонуса только в callback `onRewarded`.

## Запуск локально

Нужен интернет для загрузки Phaser и SDK с CDN.

1. Распакуйте архив.
2. Откройте терминал в папке `mini-factory-tycoon`.
3. Запустите локальный сервер:

   ```bash
   python -m http.server 8000
   ```

4. Откройте `http://localhost:8000`.

Не открывайте `index.html` двойным щелчком: ES-модули браузера должны загружаться через HTTP.

## Управление

- `W A S D` или стрелки — ходить.
- `E` или `Пробел` — взаимодействовать с ближайшим объектом.
- На мобильном — экранный D-pad и кнопка действия.

## Важные замечания перед публикацией

- Сейчас это MVP-прототип, а не готовая к модерации коммерческая версия.
- Сохранения пока локальные. Для релиза нужно добавить облачные сохранения через `ysdk.getPlayer()`.
- SDK Яндекс Игр и рекламные методы полноценно работают только внутри платформы.
- Перед публикацией проверьте актуальные требования, загрузку, паузу, звук, рекламу, мобильное управление и сохранения.
- Версия Phaser закреплена на `3.90.0` через CDN. Официальная документация: https://phaser.io/oss/docs/
- Документация Yandex Games SDK: https://yandex.ru/dev/games/doc/ru/
